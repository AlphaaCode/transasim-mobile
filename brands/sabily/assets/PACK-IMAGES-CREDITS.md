# Pack header images

Bundled stand-ins for the photo a pack card shows until the backend supplies
one per pack (`visuals.packImages` in `brand.json`): one per image region, plus
per-country overrides. All are **CC0**, so no attribution is required in the
app; each licence was checked from the file's own Wikimedia Commons metadata on
2026-09-14. Resized to 1200x675 for the 128 dp card header.
